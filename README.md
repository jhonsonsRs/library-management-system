# Library Management System — C++

A simple terminal-based library management system written in C++. Allows you to register students and books, handle loans and returns, all stored in memory during runtime.

## Features

- Register, edit, and remove students and books
- Lend books to students and track returns
- View active loans, available books, and registered students

## Compile & Run

```bash
g++ library.cpp -o library -std=c++17
./library
```
